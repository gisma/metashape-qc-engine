# Prior workflow versions

This directory contains archived workflow code and configuration files for older Metashape versions.

The files in this directory are retained as historical reference material and for compatibility checks against earlier AM2 / automate-metashape workflow states.

They are not the active runtime core of `metashape-qc-engine`.

Current workflow execution should use the top-level `python/`, `config/`, `scripts/`, and `metashape_qc_engine/` components unless an older Metashape compatibility case is being examined explicitly.
